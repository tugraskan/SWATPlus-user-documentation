# idc\_till

Selects the tillage method used by the carbon routine. It is used only when carbon is set to 2.

| Value | Tillage method     |
| ----- | ------------------ |
| 1     | DSSAT              |
| 2     | EPIC               |
| 3     | Kemanian (default) |
| 4     | DNDC               |
