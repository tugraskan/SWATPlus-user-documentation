# dorm\_hr

**Code reference:** `bsn_prm%dorm_hr`

**Declared type:** `basin_parms` ([reader](https://github.com/swat-model/swatplus/blob/6f515368525e7d84089ae0f9d33f4c9115de5679/src/basin_read_prm.f90#L24), [declaration](https://github.com/swat-model/swatplus/blob/6f515368525e7d84089ae0f9d33f4c9115de5679/src/basin_module.f90#L116)).

The maximum day length minus _dorm\_hr_ is equal to when dormancy occurs.&#x20;
