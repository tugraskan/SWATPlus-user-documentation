# plaps

**Code reference:** `bsn_prm%plaps`

**Declared type:** `basin_parms` ([reader](https://github.com/swat-model/swatplus/blob/6f515368525e7d84089ae0f9d33f4c9115de5679/src/basin_read_prm.f90#L24), [declaration](https://github.com/swat-model/swatplus/blob/6f515368525e7d84089ae0f9d33f4c9115de5679/src/basin_module.f90#L117)).

A positive value denotes an increase in precipitation with an increase in elevation while a negative value denotes a decrease in precipitation with an increase in elevation.
