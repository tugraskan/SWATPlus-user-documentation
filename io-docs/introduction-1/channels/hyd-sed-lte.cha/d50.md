# d50

**Code reference:** `sd_chd(idb)%d50` ([declaration](https://github.com/swat-model/swatplus/blob/aa4179fea9c9fbb9b00efc38e3d4def3b6a3f715/src/sd_channel_module.f90#L31)).

The table below lists the D50 values of different sediment classes:

| Sediment class | Size \[µm] | Approximate size             |
| -------------- | ---------- | ---------------------------- |
| Boulders       |  > 256,000 |  > Volley ball               |
| Cobbles        |  > 64,000  |  > Tennis ball               |
| Pebbles        |  > 2,000   |  > Match Head                |
| Coarse Sand    |  1,500     |                              |
| Medium Sand    |  375       |                              |
| Fine Sand      |  94        |                              |
| Coarse Silt    |  47        |                              |
| Medium Silt    | 11.7       | Not visible to the human eye |
| Fine Silt      |  4.9       |                              |
| Clay           |  1.95      |                              |

{% hint style="warning" %}

On SWAT+ dev the entered `d50` is used in bed erosion: the critical velocity is `0.293 × sqrt(d50)` ([`sd_channel_sediment3.f90`](https://github.com/swat-model/swatplus/blob/aa4179fea9c9fbb9b00efc38e3d4def3b6a3f715/src/sd_channel_sediment3.f90#L273-L288)). (SWAT+ main reset `d50` to `1.0` on every call, so the input had no effect.)

{% endhint %}
