# d50

**Code reference:** `sd_chd(idb)%d50` ([declaration](https://github.com/swat-model/swatplus/blob/aa4179fea9c9fbb9b00efc38e3d4def3b6a3f715/src/sd_channel_module.f90#L31)).

The table below lists the D50 values of different sediment classes:

| Sediment class | Size \[µm] | Approximate size             |
| -------------- | ---------- | ---------------------------- |
| Boulders       |  > 256,000 |  > Volley ball               |
| Cobbles        |  > 64,000  |  > Tennis ball               |
| Pebbles        |  > 2,000   |  > Match Head                |
| Coarse Sand    |  1,500     |                              |
| Medium Sand    |  375       |                              |
| Fine Sand      |  94        |                              |
| Coarse Silt    |  47        |                              |
| Medium Silt    | 11.7       | Not visible to the human eye |
| Fine Silt      |  4.9       |                              |
| Clay           |  1.95      |                              |

{% hint style="warning" %}

SWAT+ main (6f515368) resets `d50` to `1.0` each time [`sd_channel_sediment3.f90`](https://github.com/swat-model/swatplus/blob/6f515368525e7d84089ae0f9d33f4c9115de5679/src/sd_channel_sediment3.f90#L80) runs, before `d50` is used at [`sd_channel_sediment3.f90`](https://github.com/swat-model/swatplus/blob/6f515368525e7d84089ae0f9d33f4c9115de5679/src/sd_channel_sediment3.f90#L252-L255). Based on source reading, changing the value in `hyd-sed-lte.cha` does not affect simulation results.

{% endhint %}
