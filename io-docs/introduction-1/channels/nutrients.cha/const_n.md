# const\_n

**Code reference:** `ch_nut(ich)%k_n` ([declaration](https://github.com/swat-model/swatplus/blob/aa4179fea9c9fbb9b00efc38e3d4def3b6a3f715/src/channel_data_module.f90#L150)).

The Michaelis-Menton half-saturation constant for N defines the concentration of nitrogen, at which algal growth is limited to 50% of the maximum growth rate.
