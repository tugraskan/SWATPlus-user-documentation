# lt\_co

**Code reference:** `ch_nut(ich)%k_l`

**Declared type:** `channel_nut_data` ([reader](https://github.com/swat-model/swatplus/blob/6f515368525e7d84089ae0f9d33f4c9115de5679/src/ch_read_nut.f90#L57), [declaration](https://github.com/swat-model/swatplus/blob/6f515368525e7d84089ae0f9d33f4c9115de5679/src/channel_data_module.f90#L149)).

Enter lt_co in kJ/(m^2*min). SWAT+ converts the value to MJ/(m^2*hr) after reading it.
