# no2n\_no3n

**Code reference:** `ch_nut(ich)%bc2` ([declaration](https://github.com/swat-model/swatplus/blob/aa4179fea9c9fbb9b00efc38e3d4def3b6a3f715/src/channel_data_module.f90#L129)).

Enter this field in 1/day. After reading it, SWAT+ divides the value by the number of routing time steps per day to obtain the value used for each routing step.
