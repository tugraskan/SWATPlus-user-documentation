# tp_slp

**Code reference:** `rte_nut(ich)%tp_slp` ([declaration](https://github.com/swat-model/swatplus/blob/aa4179fea9c9fbb9b00efc38e3d4def3b6a3f715/src/channel_data_module.f90#L18)).

Slope of the total phosphorus reduction equation relating turbidity reduction to total phosphorus reduction (`del ppm/ppm`, struct default `0.375`). *(Note: In SWAT+ main (6f515368) and dev (aa4179fe), this column is parsed into memory but is not used in simulation calculations).*
