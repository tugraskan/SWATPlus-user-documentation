# tss_slp

**Code reference:** `rte_nut(ich)%tss_slp` ([declaration](https://github.com/swat-model/swatplus/blob/aa4179fea9c9fbb9b00efc38e3d4def3b6a3f715/src/channel_data_module.f90#L16)).

Slope of the total suspended solids (TSS) reduction equation relating inflow turbidity to TSS reduction (`del ppm/ppm`, struct default `0.457`). *(Note: In SWAT+ main (6f515368), this column is parsed into memory but is not used in simulation calculations).*
