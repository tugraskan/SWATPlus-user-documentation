# turb_slp

**Code reference:** `rte_nut(ich)%turb_slp` ([declaration](https://github.com/swat-model/swatplus/blob/aa4179fea9c9fbb9b00efc38e3d4def3b6a3f715/src/channel_data_module.f90#L14)).

Slope of the turbidity reduction equation relating inflow turbidity to turbidity reduction (`del ppm/ppm`, struct default `-0.0002`). *(Note: In SWAT+ main (6f515368) and dev (aa4179fe), this column is parsed into memory but is not used in simulation calculations).*
