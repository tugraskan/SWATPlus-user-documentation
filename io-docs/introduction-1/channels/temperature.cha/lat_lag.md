# lat_lag

**Code reference:** `w_temp(ich_temp)%lat_lag` ([declaration](https://github.com/swat-model/swatplus/blob/aa4179fea9c9fbb9b00efc38e3d4def3b6a3f715/src/channel_data_module.f90#L177)).

Average air temperature lag in days (`5–10`, struct default `10`) intended for lateral flow temperature calculation in [`ch_temp.f90`](https://github.com/swat-model/swatplus/blob/6f515368525e7d84089ae0f9d33f4c9115de5679/src/ch_temp.f90#L254-L269).
