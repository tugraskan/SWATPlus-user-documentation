# sno_mlt

**Code reference:** `w_temp(ich_temp)%sno_mlt` ([declaration](https://github.com/swat-model/swatplus/blob/aa4179fea9c9fbb9b00efc38e3d4def3b6a3f715/src/channel_data_module.f90#L171)).

Dimensionless coefficient (struct default `1.0`) intended to scale the snowmelt temperature contribution in [`ch_temp.f90`](https://github.com/swat-model/swatplus/blob/aa4179fea9c9fbb9b00efc38e3d4def3b6a3f715/src/ch_temp.f90#L329).
