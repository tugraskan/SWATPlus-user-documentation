# Climate

SWAT+ requires daily data for precipitation, maximum and minimum air temperature, solar radiation, relative humidity, and wind speed. The model can read in observed weather data or generate values using the weather generator. Climate data will be generated in two instances: when the user specifies that simulated weather data will be used or when there are missing values in the observed weather data. A Global Weather Generator Database containing weather generator datasets in SWAT+ format for almost 180,000 stations across the globe can be downloaded from the SWAT website: [https://swat.tamu.edu/data/](https://swat.tamu.edu/data/).

If observed data is used, one data file has to be provided for each station and variable. The data files for precipitation, temperature, solar radiation, relative humidity, and wind speed commonly use .pcp, .tmp or .tem, .slr, .hmd, and .wnd, respectively. The readers open the names supplied in the lists. The names of all available data files for precipitation, temperature, solar radiation, relative humidity, and wind speed will be listed in [**pcp.cli**](pcp.cli-and-precipitation-data-files.md), [**tmp.cli**](tmp.cli-and-temperature-data-files.md), [**slr.cli**](slr.cli-and-solar-radiation-data-files.md), [**hmd.cli**](hmd.cli-and-humidity-data-files.md), and [**wnd.cli**](wnd.cli-and-wind-speed-data-files.md), respectively.

{% hint style="info" %}
For measured subdaily precipitation, provide one value per simulation step. SWAT+ also has a generated subdaily path. See [precipitation input](pcp.cli-and-precipitation-data-files.md) for the reader contract and the missing-data limitation.
{% endhint %}

During project setup, stations can be selected by proximity to each object. During simulation, SWAT+ resolves the weather station by the name stored in the connectivity file. See [hyd_read_connect.f90](https://github.com/swat-model/swatplus/blob/aa4179fea9c9fbb9b00efc38e3d4def3b6a3f715/src/hyd_read_connect.f90#L336-L339). Because the precipitation, temperature, solar radiation, relative humidity, and wind speed stations might be at different locations, several combinations of weather stations might be needed for a SWAT+ setup. These combinations will be listed as a record in [**weather-sta.cli**](weather-sta.cli/). Each of them will be given a unique name, which is referenced by the connect files for the different spatial objects. In addition, the name of the selected weather generator station will be specified, which points to [**weather-wgn.cli**](weather-wgn.cli/). Finally, the user has the option to specify the name of an atmospheric deposition record, which points to [**atmo.cli**](atmo.cli/).

The [weather-sta.cli table](weather-sta.cli/README.md) links each station field to its input. [Measured PET](pet.cli/README.md) and the [weather generator](weather-wgn.cli/README.md) have separate readers. [Constituent deposition](cs_atmo.cli/README.md) and [salt deposition](salt_atmo.cli/README.md) use the station order and timestep from [atmo.cli](atmo.cli/README.md). Annual [CO₂ concentrations](co2_yr.dat/README.md) apply across stations.
