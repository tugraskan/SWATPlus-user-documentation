# no3_rf

Nitrate nitrogen concentration in rain in mg/L. SWAT+ computes the wet load in kg/ha as $0.01 C P$, where $C$ is the selected period concentration and $P$ is daily precipitation in mm.

See [nut_nrain.f90](https://github.com/swat-model/swatplus/blob/aa4179fea9c9fbb9b00efc38e3d4def3b6a3f715/src/nut_nrain.f90#L44-L65).
