# num_sta

Number of station blocks. SWAT+ allocates the station array using this count and reads that many blocks.

See [cli_read_atmodep.f90](https://github.com/swat-model/swatplus/blob/aa4179fea9c9fbb9b00efc38e3d4def3b6a3f715/src/cli_read_atmodep.f90#L36-L37) and [cli_read_atmodep.f90](https://github.com/swat-model/swatplus/blob/aa4179fea9c9fbb9b00efc38e3d4def3b6a3f715/src/cli_read_atmodep.f90#L69-L74).
