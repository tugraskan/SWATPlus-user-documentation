# yrs

**Code reference:** `co2_inc%yrs` ([declaration](https://github.com/swat-model/swatplus/blob/aa4179fea9c9fbb9b00efc38e3d4def3b6a3f715/src/co2_read.f90#L29)).

Total number of annual CO2 records (integer) that follow in this file, used to size the internal storage array.

A missing file or zero count uses the basin CO₂ value for all simulated years. See [co2_read.f90](https://github.com/swat-model/swatplus/blob/aa4179fea9c9fbb9b00efc38e3d4def3b6a3f715/src/co2_read.f90#L66-L75).
