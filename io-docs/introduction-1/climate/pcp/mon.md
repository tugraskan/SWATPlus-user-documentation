# mon

Calendar month, from 1 to 12. Input order within each day determines the storage slot.

*(Note: In SWAT+ main (6f515368), this column is parsed into memory but is not used in simulation calculations).*

See [cli_pmeas.f90](https://github.com/swat-model/swatplus/blob/aa4179fea9c9fbb9b00efc38e3d4def3b6a3f715/src/cli_pmeas.f90#L120-L139).
