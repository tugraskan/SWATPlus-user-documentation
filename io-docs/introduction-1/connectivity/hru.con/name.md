# name

**Code reference:** `ob(i)%name`

**Declared type:** `object_connectivity` ([reader](https://github.com/swat-model/swatplus/blob/6f515368525e7d84089ae0f9d33f4c9115de5679/src/hyd_read_connect.f90#L298), [declaration](https://github.com/swat-model/swatplus/blob/6f515368525e7d84089ae0f9d33f4c9115de5679/src/hydrograph_module.f90#L332)).

The SWAT+ Editor assigns a name to every object. SWAT+ writes this name to output files; changing it changes the output label but does not affect model calculations.
