# num\_metals

**Code reference:** `cs_db%num_metals` ([`declaration`](https://github.com/swat-model/swatplus/blob/aa4179fea9c9fbb9b00efc38e3d4def3b6a3f715/src/constituent_mass_module.f90#L21), [`read`](https://github.com/swat-model/swatplus/blob/aa4179fea9c9fbb9b00efc38e3d4def3b6a3f715/src/constit_db_read.f90#L48-L51)).

Number of heavy metals carried in the simulation. The default is 0. It sets how many names are read from the [metals](metals.md) line and how many heavy-metal values other input files must supply. Heavy-metal export-coefficient and delivery-ratio files are read only when it is above 0 ([`exco_db_read.f90`](https://github.com/swat-model/swatplus/blob/aa4179fea9c9fbb9b00efc38e3d4def3b6a3f715/src/exco_db_read.f90#L59), [`dr_db_read.f90`](https://github.com/swat-model/swatplus/blob/aa4179fea9c9fbb9b00efc38e3d4def3b6a3f715/src/dr_db_read.f90#L59)).
