# hl\_soil

**Code reference:** `pestdb(ip)%soil_hlife`

**Declared type:** `pesticide_db` ([reader](https://github.com/swat-model/swatplus/blob/6f515368525e7d84089ae0f9d33f4c9115de5679/src/pest_parm_read.f90#L48), [declaration](https://github.com/swat-model/swatplus/blob/6f515368525e7d84089ae0f9d33f4c9115de5679/src/pesticide_data_module.f90#L10)).

The half-life for a pesticide defines the number of days required for a given pesticide concentration to be reduced by one-half. The soil half-life entered for a pesticide is a lumped parameter that includes the net effect of volatilization, photolysis, hydrolysis, biological degradation, and chemical reactions.
