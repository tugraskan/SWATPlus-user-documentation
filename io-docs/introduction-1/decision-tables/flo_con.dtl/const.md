# const

**Code reference:** `dtbl_flo(i)%act(iac)%const` ([declaration](https://github.com/swat-model/swatplus/blob/aa4179fea9c9fbb9b00efc38e3d4def3b6a3f715/src/conditional_module.f90#L23)).

Primary value used by the [option](option.md): a demand in m³ for `set_dmd`, a target fraction of capacity for the fill options, a fraction for `duty_fr` and `frac`, and a tile-flow depth in mm for `flo_mm`, `min_mm`, and `max_mm`. For `duty_reset` it is the source number.
