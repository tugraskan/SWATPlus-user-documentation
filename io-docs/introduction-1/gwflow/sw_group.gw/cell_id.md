# cell_id

**Code reference:** `gw_gwsw_group(i,j)` ([declaration](https://github.com/swat-model/swatplus/blob/aa4179fea9c9fbb9b00efc38e3d4def3b6a3f715/src/gwflow_module.f90#L219), [read](https://github.com/swat-model/swatplus/blob/aa4179fea9c9fbb9b00efc38e3d4def3b6a3f715/src/gwflow_read.f90#L2333)).

Number of a cell in the group. The output sums the daily exchange with channels for these cells ([`gwflow_read.f90`](https://github.com/swat-model/swatplus/blob/aa4179fea9c9fbb9b00efc38e3d4def3b6a3f715/src/gwflow_read.f90#L2332-L2337)). With `grid_type` = `structured`, SWAT+ maps cell numbers through an identity list, so structured and unstructured grids both use cell numbers 1 to `ncell` ([`gwflow_read.f90`](https://github.com/swat-model/swatplus/blob/aa4179fea9c9fbb9b00efc38e3d4def3b6a3f715/src/gwflow_read.f90#L313-L319)).
