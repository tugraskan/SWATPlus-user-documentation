# ob\_name

**Code reference:** `ob_name` ([declaration](https://github.com/swat-model/swatplus/blob/aa4179fea9c9fbb9b00efc38e3d4def3b6a3f715/src/recall_read.f90#L18), [read](https://github.com/swat-model/swatplus/blob/aa4179fea9c9fbb9b00efc38e3d4def3b6a3f715/src/recall_read.f90#L164-L170)).

Character label (`character(len=16)`) indicating the spatial object name on each row.

*(Note: In SWAT+ main (6f515368), this column is parsed into memory but is not used in simulation calculations).*
