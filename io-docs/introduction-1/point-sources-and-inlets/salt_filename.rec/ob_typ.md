# ob\_typ

**Code reference:** `ob_typ` ([declaration](https://github.com/swat-model/swatplus/blob/aa4179fea9c9fbb9b00efc38e3d4def3b6a3f715/src/recall_read_salt.f90#L16), [read](https://github.com/swat-model/swatplus/blob/aa4179fea9c9fbb9b00efc38e3d4def3b6a3f715/src/recall_read_salt.f90#L200)).

Character label (`character(len=8)`) indicating the spatial object type on each row.

*(Note: In SWAT+ main (6f515368), this column is parsed into memory but is not used in simulation calculations).*
