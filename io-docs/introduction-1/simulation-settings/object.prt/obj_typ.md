# obj\_typ

Output can be printed for the following types of objects:

| Object Code | Description |
| --- | --- |
| hru | HRU |
| hlt | HRU-LTE |
| ru | Routing Unit |
| res | Reservoir |
| cha | Channel |
| exc | Export Coefficient |
| dr | Delivery Ratio |
| out | Outlet |
| sdc | SWAT-DEG channel |
