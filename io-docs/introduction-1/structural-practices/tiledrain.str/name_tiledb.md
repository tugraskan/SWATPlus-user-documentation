# name (tiledrain.str)

**Code reference:** `sdr(isdr)%name` ([declaration](https://github.com/swat-model/swatplus/blob/aa4179fea9c9fbb9b00efc38e3d4def3b6a3f715/src/hru_module.f90#L86)).

The name of the tile drain record is a primary key referenced by [tile](../../landuse-and-management/landuse.lum/tile.md) in [**landuse.lum**](../../landuse-and-management/landuse.lum/). All names in the **tiledrain.str** file must be unique.
