# evap

**Code reference:** `wet_hyddb(ires)%evrsv`

**Declared type:** `wetland_hyd_data` ([reader](https://github.com/swat-model/swatplus/blob/6f515368525e7d84089ae0f9d33f4c9115de5679/src/wet_read_hyd.f90#L57), [declaration](https://github.com/swat-model/swatplus/blob/6f515368525e7d84089ae0f9d33f4c9115de5679/src/reservoir_data_module.f90#L89)).

This coefficient is a linear multiplier for PET that can be used to de- or increase wetland evaporation.
