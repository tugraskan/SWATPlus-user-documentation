# name (hydrology.wet)

**Code reference:** `wet_hyddb(ires)%name`

**Declared type:** `wetland_hyd_data` ([reader](https://github.com/swat-model/swatplus/blob/6f515368525e7d84089ae0f9d33f4c9115de5679/src/wet_read_hyd.f90#L57), [declaration](https://github.com/swat-model/swatplus/blob/6f515368525e7d84089ae0f9d33f4c9115de5679/src/reservoir_data_module.f90#L83)).

The name of the wetland hydrology record is a primary key referenced by [hyd](../wetland.wet/hyd.md) in [**wetland.wet**](../wetland.wet/). All names in the **hydrology.wet** file must be unique.
