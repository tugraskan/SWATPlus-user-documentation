# name (hydrology.wet)

**Code reference:** `wet_hyddb(ires)%name` ([declaration](https://github.com/swat-model/swatplus/blob/aa4179fea9c9fbb9b00efc38e3d4def3b6a3f715/src/reservoir_data_module.f90#L83)).

The name of the wetland hydrology record is a primary key referenced by [hyd](../wetland.wet/hyd.md) in [**wetland.wet**](../wetland.wet/). All names in the **hydrology.wet** file must be unique.
