# name

**Code reference:** `ob(iob)%name` ([declaration](https://github.com/swat-model/swatplus/blob/aa4179fea9c9fbb9b00efc38e3d4def3b6a3f715/src/hydrograph_module.f90#L335)); `bsn%name` ([declaration](https://github.com/swat-model/swatplus/blob/aa4179fea9c9fbb9b00efc38e3d4def3b6a3f715/src/basin_module.f90#L10)).

The aquifer object name in individual output, or the basin name in basin-average output.

This is an identifier, label, or date component; it has no physical unit.
