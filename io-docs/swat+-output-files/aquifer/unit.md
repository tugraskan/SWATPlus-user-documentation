# unit

**Code reference:** `iaq` ([declaration](https://github.com/swat-model/swatplus/blob/aa4179fea9c9fbb9b00efc38e3d4def3b6a3f715/src/aquifer_output.f90#L10)); `"       1"` ([writer](https://github.com/swat-model/swatplus/blob/aa4179fea9c9fbb9b00efc38e3d4def3b6a3f715/src/basin_aquifer_output.f90#L29)).

Identifies the aquifer represented by an individual-aquifer row. Basin rows print 1 instead of an aquifer identifier.

This is an identifier, label, or date component; it has no physical unit.
