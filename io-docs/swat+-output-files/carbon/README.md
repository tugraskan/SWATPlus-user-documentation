# Carbon

### Carbon-specific Outputs

See [Modern Carbon and Nitrogen Outputs](modern-carbon-nitrogen.md) for the current `hru_ncycle`, `hru_carb_gl`, `hru_scf`, LSU, and plant-carbon status families. The pages below describe the legacy layered and diagnostic carbon reports.

For the legacy reports below, use named rows (`use_obj_lbls = y`) in [print.prt](../../introduction-1/simulation-settings/print.prt/README.md). Use `hru_cb` for the carbon balance or `hru_cb_vars` for decomposition diagnostics. For `hru_cb`, choose `y` for summary output or lowercase `l` to add layer rows; on SWAT+ dev the extra diagnostic files are switched on by [cbn\_diag\_int](../../introduction-1/carbon/carbon.bsn/cbn_diag_int.md) in carbon.bsn, not by `l`. For [`hru_cb_vars`](output-files-generated-by-hru_cb_vars.md), either value requests layer rows. The legacy time-series writers run at those three intervals. The decomposition diagnostics require `carbon = 2` in [codes.bsn](../../introduction-1/basin-1/codes.bsn/README.md). See [Soil](../soil/README.md#how-to-produce-these-files) for the legacy beginning and ending snapshots. [Legacy print rows](https://github.com/swat-model/swatplus/blob/aa4179fea9c9fbb9b00efc38e3d4def3b6a3f715/src/basin_print_codes_read.f90#L408), [Legacy write calls](https://github.com/swat-model/swatplus/blob/aa4179fea9c9fbb9b00efc38e3d4def3b6a3f715/src/command.f90#L539-L548)
