# bank_no3

**Code reference:** `ch_sed_bud(ichan)%bank_no3` ([declaration](https://github.com/swat-model/swatplus/blob/aa4179fea9c9fbb9b00efc38e3d4def3b6a3f715/src/sd_channel_module.f90#L75)).

The bank erosion producer sets the nitrate component to zero. [Nutrient budget calculation](channel-nutrient-sediment-budget.md#how-the-nutrient-values-are-formed).

**Unit:** kg.

Monthly and yearly rows sum daily values. The average-annual row divides the accumulated value by the number of printed years.
