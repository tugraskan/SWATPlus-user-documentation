# san_out

**Code reference:** `ch_out_d(ichan)%san` ([declaration](https://github.com/swat-model/swatplus/blob/aa4179fea9c9fbb9b00efc38e3d4def3b6a3f715/src/hydrograph_module.f90#L43)).

The routed sand fraction comes from incoming and stored sand. The bulk sediment adjustments for erosion and deposition do not add or remove sand in this field. [Sediment and nutrient calculations](sd-channel-general.md#where-the-sediment-and-nutrient-values-come-from)

**Unit:** tons.

The same printed heading can appear in daily, monthly, yearly, and average-annual variants of this family. The reporting interval changes the row period; this page does not infer a total-versus-average rule beyond what the family output and source establish.
