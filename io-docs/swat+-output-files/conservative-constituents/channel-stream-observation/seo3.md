# seo3 conc (g/m3)

**Code reference:** `chcs_d(chan_id)%cs(2)%conc` ([writer](https://github.com/swat-model/swatplus/blob/aa4179fea9c9fbb9b00efc38e3d4def3b6a3f715/src/cs_str_output.f90#L41)).

**Printed header value:** `third set of columns:   seo3 conc (g/m3)` ([header](https://github.com/swat-model/swatplus/blob/aa4179fea9c9fbb9b00efc38e3d4def3b6a3f715/src/cs_cha_read.f90#L79)).

The third set of columns holds the concentration of the second constituent slot, which the source comment labels seo3, for each listed channel. The source comment gives the unit as g/m3. The values are written with an `e14.6` edit descriptor. [Value loop](https://github.com/swat-model/swatplus/blob/aa4179fea9c9fbb9b00efc38e3d4def3b6a3f715/src/cs_str_output.f90#L37-L42), [format](https://github.com/swat-model/swatplus/blob/aa4179fea9c9fbb9b00efc38e3d4def3b6a3f715/src/cs_str_output.f90#L68)
