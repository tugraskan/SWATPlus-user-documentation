# seo4 conc (g/m3)

**Code reference:** `chcs_d(chan_id)%cs(1)%conc` ([writer](https://github.com/swat-model/swatplus/blob/aa4179fea9c9fbb9b00efc38e3d4def3b6a3f715/src/cs_str_output.f90#L35)).

**Printed header value:** `second set of columns:  seo4 conc (g/m3)` ([header](https://github.com/swat-model/swatplus/blob/aa4179fea9c9fbb9b00efc38e3d4def3b6a3f715/src/cs_cha_read.f90#L78)).

The second set of columns holds the concentration of the first constituent slot, which the source comment labels seo4, for each listed channel. The source comment gives the unit as g/m3. The values are written with an `e14.6` edit descriptor.
