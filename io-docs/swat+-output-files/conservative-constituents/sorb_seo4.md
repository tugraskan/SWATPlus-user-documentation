# sorb_seo4

**Code reference:** `hcsb_d(j)%cs(ics)%conc` ([declaration](https://github.com/swat-model/swatplus/blob/aa4179fea9c9fbb9b00efc38e3d4def3b6a3f715/src/cs_module.f90#L27)).

The printed heading denotes soil sorption (kg/ha). With three configured constituents, the value at this position is soil-water concentration in g/m3. See the [reporting periods](hru.md#reporting-periods) for aggregation.
