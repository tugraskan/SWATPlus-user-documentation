# p25

**Code reference:** `ob(icmd)%fdc%p_md%p(10)` ([declaration](https://github.com/swat-model/swatplus/blob/aa4179fea9c9fbb9b00efc38e3d4def3b6a3f715/src/hydrograph_module.f90#L302)).

The printed heading `p25` is associated with nominal 25% exceedance. The annual curve selects ranked day 91 from flows sorted in descending order, using the [fixed rank table](https://github.com/swat-model/swatplus/blob/aa4179fea9c9fbb9b00efc38e3d4def3b6a3f715/src/hydrograph_module.f90#L307). A 100-day year still uses the 91st-highest flow. The writer takes the median of the annual values at this rank. [Partial years and fixed ranks](README.md#partial-years-and-fixed-ranks)

**Unit:** m3/s.

This field belongs to a fixed or event-style report rather than the standard daily/monthly/yearly/average-annual series.
