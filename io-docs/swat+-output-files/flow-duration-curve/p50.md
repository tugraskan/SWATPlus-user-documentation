# p50

**Code reference:** `ob(icmd)%fdc%p_md%p(15)` ([declaration](https://github.com/swat-model/swatplus/blob/aa4179fea9c9fbb9b00efc38e3d4def3b6a3f715/src/hydrograph_module.f90#L302)).

The printed heading `p50` is associated with nominal 50% exceedance. The annual curve selects ranked day 182 from flows sorted in descending order, using the [fixed rank table](https://github.com/swat-model/swatplus/blob/aa4179fea9c9fbb9b00efc38e3d4def3b6a3f715/src/hydrograph_module.f90#L307). A 100-day year starting January 1 contributes a default zero at this rank. The writer includes that zero when taking the median across years. [Partial years and fixed ranks](README.md#partial-years-and-fixed-ranks)

**Unit:** m3/s.

This field belongs to a fixed or event-style report rather than the standard daily/monthly/yearly/average-annual series.
