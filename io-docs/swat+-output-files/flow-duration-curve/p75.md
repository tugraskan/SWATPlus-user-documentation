# p75

**Code reference:** `ob(icmd)%fdc%p_md%p(20)` ([declaration](https://github.com/swat-model/swatplus/blob/aa4179fea9c9fbb9b00efc38e3d4def3b6a3f715/src/hydrograph_module.f90#L302)).

The printed heading `p75` is associated with nominal 75% exceedance. The annual curve selects ranked day 274 from flows sorted in descending order, using the [fixed rank table](https://github.com/swat-model/swatplus/blob/aa4179fea9c9fbb9b00efc38e3d4def3b6a3f715/src/hydrograph_module.f90#L307). The writer takes the median of the annual values at this rank. See the [table notes on partial years](README.md).

**Unit:** m3/s.

This field belongs to a fixed or event-style report rather than the standard daily/monthly/yearly/average-annual series.
