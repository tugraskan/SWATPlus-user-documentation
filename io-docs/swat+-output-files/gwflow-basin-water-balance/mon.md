# mon

**Code reference:** `time%mo` ([declaration](https://github.com/swat-model/swatplus/blob/aa4179fea9c9fbb9b00efc38e3d4def3b6a3f715/src/time_module.f90#L19)).

The calendar month associated with the output row.

Monthly and annual files identify the reporting boundary in this column.

This is an identifier, label, or date component; it has no physical unit.
