# GWFlow Canal Water Balance

`gwflow_canal_wb_day.txt` uses the fixed 11-column schema `jday`, `mon`, `day`, `yr`, `unit`, `gis_id`, `name`, `diversion`, `storage`, `pond_xfer`, and `seepage`. The four water-balance values are m³. Daily rows use the [`gwflow_flux` switch](README.md#defaults-when-a-print-row-is-absent), which defaults to on if the row is absent. The opener also requires `canal = 1` in `codes.gw` and `gwflow_canal.con`. [Print switch](https://github.com/swat-model/swatplus/blob/aa4179fea9c9fbb9b00efc38e3d4def3b6a3f715/src/gwflow_read.f90#L307-L311), [Canal setup](https://github.com/swat-model/swatplus/blob/aa4179fea9c9fbb9b00efc38e3d4def3b6a3f715/src/gwflow_read.f90#L1237-L1278), [Header](https://github.com/swat-model/swatplus/blob/aa4179fea9c9fbb9b00efc38e3d4def3b6a3f715/src/gwflow_read.f90#L1382-L1390)

Both identifier columns use the canal loop index, which also forms `canal_0001` and subsequent names. Each day the code initializes `diversion` by reversing the sign of the assigned Recall flow, or uses zero for an unassigned diversion. It resets `storage` to that volume and zeroes both transfer counters. Ponds take their diversion before the canal seepage step. The row then reports remaining storage, water transferred to ponds, and positive canal-to-cell seepage. Groundwater-to-canal exchange changes groundwater storage but does not credit these canal storage or seepage fields.
