# name

**Code reference:** `cell_name(i)` ([cell writer](https://github.com/swat-model/swatplus/blob/aa4179fea9c9fbb9b00efc38e3d4def3b6a3f715/src/gwflow_output.f90#L1225)).

The cell water-balance writer prints the configured cell name. Other report families use different names, such as `obs_####` for observation wells or HRU object names for pumping.

This is an identifier or label, with no physical unit.
