# GWFlow Recharge-Pond Solute Matrices

`gwflow_pond_mass_day.txt` and `gwflow_pond_conc_day.txt` share the record prefix `year, month, jday, solute_name`, followed by one value per configured pond in `ponds.gw` order. The files start with a descriptive title and have no pond-name header. Each day the writer prints NO₃ and P rows followed by any enabled salts and conservative constituents. [File opening](https://github.com/swat-model/swatplus/blob/aa4179fea9c9fbb9b00efc38e3d4def3b6a3f715/src/gwflow_read.f90#L2022-L2045), [Matrix writes](https://github.com/swat-model/swatplus/blob/aa4179fea9c9fbb9b00efc38e3d4def3b6a3f715/src/gwflow_pond.f90#L362-L426)

Mass values are kg. Concentrations are g/m³. The writer computes concentration as `mass * 1000 / storage` for positive storage and writes zero otherwise. [Concentration calculations](https://github.com/swat-model/swatplus/blob/aa4179fea9c9fbb9b00efc38e3d4def3b6a3f715/src/gwflow_pond.f90#L365-L413)

Both files open with configured ponds and the [`gwflow_flux` switch](README.md#defaults-when-a-print-row-is-absent), which defaults to on if the row is absent. The matrix writes access the first two solute entries unconditionally when that switch is active. Initialize GWFlow solutes with `solute = 1` in `codes.gw` and a valid `solute.gw` before using the switch with ponds. Without solute initialization, the matrix path can access unallocated names and zero-length pond solute arrays even if you only requested the water balance. [Print switch](https://github.com/swat-model/swatplus/blob/aa4179fea9c9fbb9b00efc38e3d4def3b6a3f715/src/gwflow_read.f90#L307-L311), [Solute names](https://github.com/swat-model/swatplus/blob/aa4179fea9c9fbb9b00efc38e3d4def3b6a3f715/src/gwflow_read.f90#L1587-L1612), [Pond arrays](https://github.com/swat-model/swatplus/blob/aa4179fea9c9fbb9b00efc38e3d4def3b6a3f715/src/gwflow_read.f90#L1968-L1975), [Matrix write gate](https://github.com/swat-model/swatplus/blob/aa4179fea9c9fbb9b00efc38e3d4def3b6a3f715/src/gwflow_pond.f90#L362-L383)
