# GWFlow Recharge-Pond Water Balance

`gwflow_pond_wb_day.txt` uses the fixed 15-column schema `jday`, `mon`, `day`, `yr`, `unit`, `gis_id`, `name`, `area`, `storage`, `rain`, `div_added`, `evap`, `recharge`, `div_spec`, and `div_unsat`. `area` is m² and the seven volume fields are m³. Both identifiers use the pond's position in `ponds.gw`, which also forms the name `pond_0001` and subsequent names. [Header and units](https://github.com/swat-model/swatplus/blob/aa4179fea9c9fbb9b00efc38e3d4def3b6a3f715/src/gwflow_read.f90#L2024-L2030), [Pond reader](https://github.com/swat-model/swatplus/blob/aa4179fea9c9fbb9b00efc38e3d4def3b6a3f715/src/gwflow_read.f90#L1932-L1957), [Writer](https://github.com/swat-model/swatplus/blob/aa4179fea9c9fbb9b00efc38e3d4def3b6a3f715/src/gwflow_pond.f90#L333-L345)

Configure `ponds.gw` and `pond_cell.gw` to get daily rows when the [`gwflow_flux` switch](README.md#defaults-when-a-print-row-is-absent) is on. The switch defaults to on if the row is absent. This also activates the [solute matrix writer](recharge-pond-solute-matrices.md), which requires initialized GWFlow solutes. The optional `pond_div.gw` supplies `div_spec` sequentially by simulation day and pond position. Without it, the code sets `div_spec` to zero. [Print switch](https://github.com/swat-model/swatplus/blob/aa4179fea9c9fbb9b00efc38e3d4def3b6a3f715/src/gwflow_read.f90#L307-L311), [Pond input and file creation](https://github.com/swat-model/swatplus/blob/aa4179fea9c9fbb9b00efc38e3d4def3b6a3f715/src/gwflow_read.f90#L1978-L2045), [Daily diversion input](https://github.com/swat-model/swatplus/blob/aa4179fea9c9fbb9b00efc38e3d4def3b6a3f715/src/gwflow_pond.f90#L52-L62)

Channel diversions report the supplied and unsatisfied volumes separately. The canal branch does the same when canal storage is positive. The outside-source branch adds the requested water directly to storage and leaves both `div_added` and `div_unsat` at zero. A pond before its start date can still print a row. After the start date, a pond without a source skips the fixed-width rows. [Diversion and start-date branches](https://github.com/swat-model/swatplus/blob/aa4179fea9c9fbb9b00efc38e3d4def3b6a3f715/src/gwflow_pond.f90#L65-L97), [Canal and outside-source branches](https://github.com/swat-model/swatplus/blob/aa4179fea9c9fbb9b00efc38e3d4def3b6a3f715/src/gwflow_pond.f90#L150-L225), [Writer position](https://github.com/swat-model/swatplus/blob/aa4179fea9c9fbb9b00efc38e3d4def3b6a3f715/src/gwflow_pond.f90#L325-L360)

Rainfall is precipitation depth times pond area. Evaporation uses potential evaporation times area and the pond evaporation coefficient, capped by available storage. Recharge sums bed hydraulic conductivity times connection area for active cells, capped by remaining pond water for each cell. `storage` is the volume remaining after those steps. [Water calculations](https://github.com/swat-model/swatplus/blob/aa4179fea9c9fbb9b00efc38e3d4def3b6a3f715/src/gwflow_pond.f90#L227-L263)
