# GWFlow Tile-Group Matrix

Set `tile = 1` in `codes.gw` and set the tile-group flag to `1` in `tile.gw`. The reader expects the number of groups, then a separator line, cell count, and one internal cell index per line for each group. The file opens when the `gwflow_flux` diagnostic switch is on. A named `gwflow_flux` row in `print.prt` enables the switch with `y` in either the daily or yearly column, and the matrix always reports daily values. The switch defaults to on when that row is absent. [Tile switch](https://github.com/swat-model/swatplus/blob/aa4179fea9c9fbb9b00efc38e3d4def3b6a3f715/src/gwflow_read.f90#L246), [print switch](https://github.com/swat-model/swatplus/blob/aa4179fea9c9fbb9b00efc38e3d4def3b6a3f715/src/gwflow_read.f90#L307-L311), [tile-group reader](https://github.com/swat-model/swatplus/blob/aa4179fea9c9fbb9b00efc38e3d4def3b6a3f715/src/gwflow_read.f90#L1017-L1059), [default](https://github.com/swat-model/swatplus/blob/aa4179fea9c9fbb9b00efc38e3d4def3b6a3f715/src/gwflow_module.f90#L26).

`gwflow_tile_group_day.txt` has a title line followed by data with the positional prefix `jday, mon, day, yr`. For `N` configured groups, the data contain `4 + N` fields for flow alone. When solutes are active, an NO3 block and a P block follow in group order, giving `4 + 3N` fields. Other solutes are omitted. Each flow is the negative of the sum of the listed cells' signed daily `tile` values, divided by 86,400 to give positive outflow in m³/s. Each listed occurrence is counted. Repeated drainage calls can replace a cell's daily contribution, as in the [cell `tile` output](tile.md). [Group calculation and writer](https://github.com/swat-model/swatplus/blob/aa4179fea9c9fbb9b00efc38e3d4def3b6a3f715/src/gwflow_simulate.f90#L129-L171), [tile assignments](https://github.com/swat-model/swatplus/blob/aa4179fea9c9fbb9b00efc38e3d4def3b6a3f715/src/gwflow_tile.f90#L53-L95).

{% hint style="warning" %}
The solute calculation uses `sum_mass / sum_tile`, where `sum_mass` retains the negative sign for mass leaving the aquifer and `sum_tile` is the flow in m³/s. It divides by the flow rate, not by daily water volume. For positive outflow, the written value is −86,400 times the concentration in g/m³ calculated from those same daily mass and water diagnostics. At zero flow the writer uses zero for both solute blocks.
{% endhint %}
