# no3_in

**Code reference:** `res_in_d(j)%no3` ([declaration](https://github.com/swat-model/swatplus/blob/aa4179fea9c9fbb9b00efc38e3d4def3b6a3f715/src/hydrograph_module.f90#L36)).

Nitrate nitrogen in the routed incoming hydrograph. GWFlow nitrate additions go directly to storage. [Nutrient block details](README.md#what-the-nutrient-blocks-include).

**Unit:** kg N.

Monthly and yearly records sum daily values. The average-annual record divides the accumulated values by the number of printed years.
