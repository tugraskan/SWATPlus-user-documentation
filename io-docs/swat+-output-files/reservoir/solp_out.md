# solp_out

**Code reference:** `res_out_d(j)%solp` ([declaration](https://github.com/swat-model/swatplus/blob/aa4179fea9c9fbb9b00efc38e3d4def3b6a3f715/src/hydrograph_module.f90#L37)).

Soluble phosphorus exported with the computed release. It excludes mass removed by groundwater seepage or allocation withdrawal. [Nutrient block details](README.md#what-the-nutrient-blocks-include).

**Unit:** kg P.

Monthly and yearly records sum daily values. The average-annual record divides the accumulated values by the number of printed years.
