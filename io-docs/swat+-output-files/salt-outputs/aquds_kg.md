# aquds_kg

**Code reference:** `salt_basin(27)` ([calculation](https://github.com/swat-model/swatplus/blob/aa4179fea9c9fbb9b00efc38e3d4def3b6a3f715/src/salt_balance.f90#L331-L352)).

Dissolved salt stored in standard aquifers or, with GWFlow enabled, in active GWFlow cells. With GWFlow enabled and solute transport disabled, the value is zero.

**Unit:** kg. The longer periods report mean daily storage.

See [reporting periods](basin-salt-balance.md#reporting-periods) for aggregation.
