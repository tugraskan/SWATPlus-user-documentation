# div_ca

**Code reference:** `asaltb_d(iaq)%salt(isalt)%div` ([declaration](https://github.com/swat-model/swatplus/blob/aa4179fea9c9fbb9b00efc38e3d4def3b6a3f715/src/salt_aquifer.f90#L13)).

Aquifer diversion slot for calcium. The header describes signed exchange, with removal negative and addition positive. The inspected 1-D path leaves the field at zero because no active producer assigns it. See [daily aquifer values](aquifer-salt.md#daily-1-d-aquifer-values).

**Unit:** kg.

The same printed heading can appear in daily, monthly, yearly, and average-annual variants of this family. The reporting interval changes the row period; this page does not infer a total-versus-average rule beyond what the family output and source establish.
