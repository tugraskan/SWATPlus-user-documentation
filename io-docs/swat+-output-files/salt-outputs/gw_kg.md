# gw_kg

**Code reference:** `salt_basin(2)` ([calculation](https://github.com/swat-model/swatplus/blob/aa4179fea9c9fbb9b00efc38e3d4def3b6a3f715/src/salt_balance.f90#L49-L70)).

Standard aquifer discharge salt, or with GWFlow the signed sum of groundwater–stream exchange and saturation-excess return. With GWFlow enabled and solute transport disabled, the value is zero.

**Unit:** kg for daily, monthly, and yearly output. The average-annual value is kg/yr.

See [reporting periods](basin-salt-balance.md#reporting-periods) for aggregation.
