# irr_na

**Code reference:** `asaltb_d(iaq)%salt(isalt)%irr` ([declaration](https://github.com/swat-model/swatplus/blob/aa4179fea9c9fbb9b00efc38e3d4def3b6a3f715/src/salt_aquifer.f90#L12)).

Aquifer irrigation slot for sodium. The inspected 1-D path leaves it at zero because the irrigation salt transfer routine has no active caller. See [daily aquifer values](aquifer-salt.md#daily-1-d-aquifer-values).

**Unit:** kg.

The same printed heading can appear in daily, monthly, yearly, and average-annual variants of this family. The reporting interval changes the row period; this page does not infer a total-versus-average rule beyond what the family output and source establish.
