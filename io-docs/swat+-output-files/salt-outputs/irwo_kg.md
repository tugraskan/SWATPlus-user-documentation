# irwo_kg

**Code reference:** `salt_basin(12)` ([calculation](https://github.com/swat-model/swatplus/blob/aa4179fea9c9fbb9b00efc38e3d4def3b6a3f715/src/salt_balance.f90#L162-L169)).

Salt assigned to outside-source irrigation in the HRU diagnostics. The field is zero on the inspected revision because it has no active producer. [HRU salt diagnostics](../hru-salt/README.md)

**Unit:** kg for daily, monthly, and yearly output. The average-annual value is kg/yr.

See [reporting periods](basin-salt-balance.md#reporting-periods) for aggregation.
