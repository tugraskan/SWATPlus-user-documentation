# soilmn_kg

**Code reference:** `salt_basin(26)` ([calculation](https://github.com/swat-model/swatplus/blob/aa4179fea9c9fbb9b00efc38e3d4def3b6a3f715/src/salt_balance.f90#L316-L329)).

Solid salt stored in five soil mineral pools. Soil mass is computed from each layer's thickness, area, and bulk density.

**Unit:** kg. The longer periods report mean daily storage.
