# clay

**Code reference:** `soil(j)%phys(ly)%clay` ([declaration](https://github.com/swat-model/swatplus/blob/aa4179fea9c9fbb9b00efc38e3d4def3b6a3f715/src/soil_module.f90#L40)).

Clay content of the model layer. A layer defined at custom depths can span more than one input layer. Matching soil tests can also change the value before initialization. [Model layer initialization](README.md#how-the-model-builds-the-printed-layers)

**Unit:** percent.
