# cbod_in

**Code reference:** `wet_in_d(j)%cbod` ([declaration](https://github.com/swat-model/swatplus/blob/aa4179fea9c9fbb9b00efc38e3d4def3b6a3f715/src/hydrograph_module.f90#L41)).

Carbonaceous biochemical oxygen demand in the incoming hydrograph. This can include routed surface runon, associated tile flow, and overbank inflow from a linked channel.
