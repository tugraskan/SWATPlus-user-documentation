# cla_stor

**Code reference:** `wet(j)%cla` ([declaration](https://github.com/swat-model/swatplus/blob/aa4179fea9c9fbb9b00efc38e3d4def3b6a3f715/src/hydrograph_module.f90#L45)).

Clay retained in the storage hydrograph. The settling routine clears the size classes when bulk sediment concentration exceeds the equilibrium threshold. A low remaining water volume clears the entire storage hydrograph. [Sediment storage](https://github.com/swat-model/swatplus/blob/aa4179fea9c9fbb9b00efc38e3d4def3b6a3f715/src/res_sediment.f90#L17-L53)

**Unit:** tons.
