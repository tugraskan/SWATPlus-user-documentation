# gis_id

GIS identifier.

**Code reference:** the [daily wetland record](https://github.com/swat-model/swatplus/blob/aa4179fea9c9fbb9b00efc38e3d4def3b6a3f715/src/wetland_output.f90#L20) writes the date, HRU number, GIS identifier, and HRU name in this order.

This field has no physical unit.
