# 1:1.2.3 Daily Solar Radiation

The solar radiation reaching the earth's surface on a given day, $$H_{day}$$, may be less than $$H_{mx}$$ due to the presence of cloud cover. The daily solar radiation data required by SWAT+ may be read from an input file or generated by the model.

The [slr field](../../../../introduction-1/climate/weather-sta.cli/slr.md) in `weather-sta.cli` selects the source. A station name selects a [solar radiation data file](../../../../introduction-1/climate/slr.cli-and-solar-radiation-data-files.md); `sim` selects generated radiation. The generator is also used when a station value is missing or the day falls outside the station file's date range. The current generated-value behavior is described below.

Table 1:1-2: Inputs relevant to daily solar radiation.

| Role | Source-code value | Input page |
| --- | --- | --- |
| Select station data or generation (`sim`) | `wst(iwst)%wco_c%sgage` | [slr in weather-sta.cli](../../../../introduction-1/climate/weather-sta.cli/slr.md) |
| Measured daily radiation | `slr(ig)%ts(time%day,yrs_to_start)` | [Solar radiation data file](../../../../introduction-1/climate/slr.cli-and-solar-radiation-data-files.md) |
| Generated daily radiation | `wgn(iwgn)%solarav(time%mo)` | Monthly [slr_ave](../../../../introduction-1/climate/weather-wgn.cli/slr_ave.md) of the selected weather generator station |
| Latitude used for solar geometry | `wgn(iwgn)%lat` | [weather-wgn.cli](../../../../introduction-1/climate/weather-wgn.cli/README.md) |

See the description for the .slr files on the [slr.cli](../../../../introduction-1/climate/slr.cli-and-solar-radiation-data-files.md) page for input and format requirements if measured daily solar radiation data is being used.

### Source Code Implementation

[`climate_control.f90`](https://github.com/swat-model/swatplus/blob/6f515368525e7d84089ae0f9d33f4c9115de5679/src/climate_control.f90#L90-L112) calls `cli_clgen` to calculate the day's `solradmx`, then either reads the station value or calls `cli_slrgen`. It also calls `cli_slrgen` if the station value is missing (`<= -97.`), including days outside the file's date range, which the code marks as `-98.`.

The [current generator routine](https://github.com/swat-model/swatplus/blob/6f515368525e7d84089ae0f9d33f4c9115de5679/src/cli_slrgen.f90#L30-L36) calculates a variable daily estimate, but its last assignment replaces that estimate with the weather generator's monthly mean:

```fortran
rav = wgn(iwgn)%solarav(time%mo) / (1. - 0.5 * wgn_pms(iwgn)%pr_wdays(time%mo))
if (wst(iwst)%weat%precip > 0.0) rav = 0.5 * rav
rx = wst(iwst)%weat%solradmx - rav
wst(iwst)%weat%solrad = rav + wgncur(3,iwgn) * rx / 4.
if (wst(iwst)%weat%solrad <= 0.) wst(iwst)%weat%solrad = .05 * wst(iwst)%weat%solradmx

wst(iwst)%weat%solrad = wgn(iwgn)%solarav(time%mo)
```

The final generated `solrad` value from this routine is therefore the monthly mean `solarav(time%mo)`. The preceding precipitation and random-residual calculations do not determine that returned value. Later [monthly climate adjustments](https://github.com/swat-model/swatplus/blob/6f515368525e7d84089ae0f9d33f4c9115de5679/src/climate_control.f90#L270-L271) may change it. The `lat` stored in an observed `.slr` file is station metadata; `cli_clgen.f90` uses the selected weather generator station's latitude for solar geometry.
