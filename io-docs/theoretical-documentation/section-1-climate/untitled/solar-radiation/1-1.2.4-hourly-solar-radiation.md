# 1:1.2.4 Hourly Solar Radiation

The extraterrestrial radiation falling on a horizontal surface during one hour is given by the equation:

$$I_0=I_{SC}E_0(\sin\delta\sin\phi+\cos\delta\cos\phi\cos\omega t)$$                                                                                              1:1.2.8       &#x20;

where $$I_0$$ is the extraterrestrial radiation for 1 hour centered around the hour angle $$\omega t$$.

An accurate calculation of the radiation for each hour of the day requires a knowledge of the difference between standard time and solar time for the location. SWAT+ simplifies its time-step solar weights by assuming that solar noon occurs at 12:00pm local standard time.&#x20;

The daily radiation can be distributed across time steps according to the relative solar-position weights. SWAT+ calculates these weights and normalizes them so the fractions sum to one, provided the sum of the weights exceeds 0.001. The implemented calculation is described below.

The earlier SWAT theory calculates hourly solar radiation at the earth’s surface with the equation:

$$I_{hr}=I_{frac} H_{day}$$                                                                                                                                                    1:1.2.9

where $$I_{hr}$$  is the solar radiation reaching the earth’s surface during a specific hour of the day                    ($$MJ m^{-2}hr^{-1}$$), $$I_{frac}$$ is the fraction of total daily radiation falling during that hour, and $$H_{day}$$ is the total solar radiation reaching the earth’s surface on that day.

The fraction of total daily radiation falling during an hour is calculated

$$I_{frac}=\frac {\displaystyle(\sin\delta\sin\phi + \cos\delta\cos\phi\cos\omega t_i)} {\displaystyle\sum_{t=SR}^{SS}(\sin\delta\sin\phi+\cos\delta\cos\phi\cos\omega t)}$$                                                                                                   1:1.2.10

where $$t_i$$ is the solar time at the midpoint of hour $$i$$. &#x20;

### Source Code Implementation

| Equation | Relationship to current SWAT+ code |
| --- | --- |
| 1:1.2.8 | Indirect. [`cli_clgen.f90`](https://github.com/swat-model/swatplus/blob/6f515368525e7d84089ae0f9d33f4c9115de5679/src/cli_clgen.f90#L92-L111) calculates only the solar-angle part, `cosrho(ii)`, without separately calculating the hourly extraterrestrial radiation $$I_0$$ or multiplying by $$I_{SC}E_0$$. |
| 1:1.2.9 | Not implemented in this version. The code writes `frad` (equation 1:1.2.10), but no routine reads it or multiplies the daily radiation into a separate `I_hr`. |
| 1:1.2.10 | Modified direct calculation. The routine clips nonpositive angle weights to zero, divides by their sum only when `totrho > 0.001`, and evaluates one weight per simulation step. Its hour angle, `(12.5 - ii) * 0.2618 * time%dtm / 60`, falls at the step midpoints only when there are 24 steps per day. No other routine reads the resulting `frad`, so these fractions do not currently affect simulated results. |

The [Fortran weighting and normalization](https://github.com/swat-model/swatplus/blob/6f515368525e7d84089ae0f9d33f4c9115de5679/src/cli_clgen.f90#L102-L118) is:

```fortran
cosrho = 0.
totrho = 0.
do ii = 1, time%step
  hr_angle = (12.5 - Real(ii)) * 0.2618 * time%dtm / 60.
  cosrho(ii) = ys + yc * Cos(hr_angle)
  if (cosrho(ii) <= 0.) cosrho(ii) = 0.
  totrho = totrho + cosrho(ii)
end do
if (totrho > 0.001) then
  do ii = 1, time%step
    frad(iwgn,ii) = cosrho(ii) / totrho
  end do
end if
```

The snippet shows the executable statements; the linked source also contains comments between them. `ys` and `yc` are calculated from latitude and declination in the same routine. When `totrho <= 0.001`, this routine does not write new `frad` values for that day.

| Steps per day | `time%step`, `time%dtm` | [step in time.sim](../../../../introduction-1/simulation-settings/time.sim/step.md) and derived minutes per step |
| Fraction of daily radiation | `frad(iwgn,ii)` | Calculated result |
