# 1:1.2 Solar Radiation

This section follows solar energy from the top of the atmosphere to the ground, then describes daily and time-step radiation and the radiation terms used in potential evapotranspiration.

The Source Code Implementation sections distinguish quantities calculated by the current SWAT+ code from intermediate theory expressions. In particular, the code calculates a clear-sky maximum, but the daily radiation used by the model may be read from a station file or generated from a weather generator's monthly mean. The net-radiation page describes the standard HRU PET calculation and notes the separate LTE HRU path.
