# 2:1.1.1.3 Retention Parameter

SWAT+ calculates the daily curve number from the water content of the soil profile. Its retention parameter, $$S$$, decreases as the soil becomes wetter. An evapotranspiration-based method from older SWAT documentation is described under **Earlier SWAT method** below; it is not implemented in this version of SWAT+.

## Daily retention from soil water

The soil-water relationship is:

$$S=S_{max}\left(1-\frac{SW}{SW+\exp(w_1-w_2 SW)}\right)$$                                                                                                          2:1.1.6

Here $$S$$ is the daily retention parameter (mm), $$S_{max}$$ is the maximum retention parameter (mm), $$SW$$ is water in the entire soil profile above wilting point (mm), and $$w_1$$ and $$w_2$$ are shape coefficients. $$S_{max}$$ is calculated from equation 2:1.1.2 using the dry-condition curve number $$CN_1$$. To obtain $$CN_1$$, SWAT+ first selects $$CN_2$$ from `cntable.lum` using the land-use curve-number pointer and the soil's hydrologic group.

The shape coefficients are found by solving equation 2:1.1.6 with three assumptions:

1. at wilting point ($$SW=0$$), the retention parameter equals $$S_{max}$$, the value for the moisture condition I curve number $$CN_1$$;
2. at the wet-condition soil water content $$SW_3$$, the retention parameter equals $$S_3$$, the value for the moisture condition III curve number $$CN_3$$; and
3. when the soil is completely saturated, it has a curve number of 99 ($$S=2.54$$ mm).

The earlier SWAT theory placed the wet-condition point at field capacity. In the current code it is

$$SW_3=FC+cn3\_swf\,(SAT-FC)$$

where $$FC$$ and $$SAT$$ are profile water contents at field capacity and saturation. The [cn3\_swf](../../../../../introduction-1/hydrology/hydrology.hyd/cn3_swf.md) input moves this point toward saturation. If the calculated point is negative, the code first replaces it with 10 mm; it then bounds the fit point between 0.05 mm and $$SAT-0.05$$ mm. For an HRU with a tile drain, [initialization sets](https://github.com/swat-model/swatplus/blob/6f515368525e7d84089ae0f9d33f4c9115de5679/src/topohyd_init.f90#L55-L58) `cn3_swf` to 0.95.

Let $$S_3$$ be the retention parameter for $$CN_3$$, $$a_3=1-S_3/S_{max}$$, and $$a_{99}=1-2.54/S_{max}$$. The shape coefficients are

$$w_1=\ln\!\left(\frac{SW_3}{a_3}-SW_3\right)+w_2 SW_3$$                                                                                                            2:1.1.7

$$w_2=\frac{\ln\!\left(\frac{SW_3}{a_3}-SW_3\right)-\ln\!\left(\frac{SAT}{a_{99}}-SAT\right)}{SAT-SW_3}$$                                                  2:1.1.8

These equations reduce to the earlier field-capacity expressions when `cn3_swf = 0` and no bound changes the fit point.

## Frozen soil and daily curve number

When the **second soil layer** is at or below 0 °C, SWAT+ adjusts the retention parameter. SWAT+ usually [adds a 10 mm surface layer](https://github.com/swat-model/swatplus/blob/6f515368525e7d84089ae0f9d33f4c9115de5679/src/soils_init.f90#L69-L81) above the layers listed in `soils.sol`, so this is usually the top layer defined in that file.

$$S_{frz}=S_{max}\left[1-\exp(-cn\_froz\,S_{soil})\right]$$                                                                                                  2:1.1.10

The [cn\_froz](../../../../../introduction-1/basin-1/parameters.bsn/cn_froz.md) input in `parameters.bsn` defaults to 0.000862; a value below $$10^{-6}$$ is [replaced by that default](https://github.com/swat-model/swatplus/blob/6f515368525e7d84089ae0f9d33f4c9115de5679/src/basin_prm_default.f90#L37). After the frozen-soil adjustment, if any, the code enforces a minimum retention of 3 mm. It then calculates the daily curve number:

$$CN=\frac{25400}{S+254}$$                                                                                                                                                        2:1.1.11

Here $$S$$ is retention after any frozen-soil adjustment and the 3 mm minimum.

## Source Code Implementation

[curno.f90](https://github.com/swat-model/swatplus/blob/6f515368525e7d84089ae0f9d33f4c9115de5679/src/curno.f90#L55-L81) calculates $$S_{max}$$ and the fit points, and [ascrv.f90](https://github.com/swat-model/swatplus/blob/6f515368525e7d84089ae0f9d33f4c9115de5679/src/ascrv.f90#L31-L33) solves for $$w_1$$ and $$w_2$$. Each day, [sq_dailycn.f90](https://github.com/swat-model/swatplus/blob/6f515368525e7d84089ae0f9d33f4c9115de5679/src/sq_dailycn.f90#L41-L55) evaluates the retention parameter and the daily curve number.

| Equation | Relationship to current SWAT+ code |
| --- | --- |
| 2:1.1.6 | Direct, with implementation bounds. The exponent is limited to ±20, and the routine uses $$S_{max}$$ when the denominator is at most 0.001. |
| 2:1.1.7–2:1.1.8 | Modified. The fit uses the wet-condition point $$SW_3$$ in place of field capacity. |
| 2:1.1.9 | Not implemented in this version; see **Earlier SWAT method** below. |
| 2:1.1.10 | Modified. The code uses the adjustable `cn_froz` coefficient in place of the fixed 0.000862 and tests the temperature of the second soil layer. |
| 2:1.1.11 | Direct, applied after the frozen-soil adjustment and the 3 mm minimum. |

The code evaluates equation 2:1.1.6 as

$$x=\min(20,\max(-20,\,w_1-w_2 SW)),\qquad S_{soil}=S_{max}\left(1-\frac{SW}{SW+\exp(x)}\right)$$

The exponent bound keeps the calculation within a finite range.

The [wet-condition fit point](https://github.com/swat-model/swatplus/blob/6f515368525e7d84089ae0f9d33f4c9115de5679/src/curno.f90#L73-L79) is calculated as:

```fortran
sumul = soil(h)%sumul
sumfc = soil(h)%sumfc + hru(h)%hyd%cn3_swf * (soil(h)%sumul - soil(h)%sumfc)
if (sumfc < 0.) then
  sumfc = 10.
end if
sumfc = max (.05, sumfc)
sumfc = amin1 (sumul-.05, sumfc)
```

The [daily retention and curve-number calculation](https://github.com/swat-model/swatplus/blob/6f515368525e7d84089ae0f9d33f4c9115de5679/src/sq_dailycn.f90#L41-L55) is:

```fortran
sw_fac = wrt(1,j) - wrt(2,j) * soil(j)%sw
if (sw_fac < -20.) sw_fac = -20.
if (sw_fac > 20.) sw_fac = 20.

if ((soil(j)%sw + Exp(sw_fac)) > 0.001) then
  r2 = smx(j) * (1. - soil(j)%sw / (soil(j)%sw + Exp(sw_fac)))
else
  r2 = smx(j)
end if

if (soil(j)%phys(2)%tmp <= 0.) r2 = smx(j) * (1. - Exp(- bsn_prm%cn_froz * r2))
r2 = Max(3.,r2)

cnday(j) = 25400. / (r2 + 254.)
```

| Equation term or result | Source-code value | Origin |
| --- | --- | --- |
| Starting $$CN_2$$ | `cn2(j)` | [landuse.lum curve-number pointer](../../../../../introduction-1/landuse-and-management/landuse.lum/cn2.md), [cntable.lum](../../../../../introduction-1/landuse-and-management/cntable.lum/README.md), and [soil hydrologic group](../../../../../introduction-1/soils/soils.sol/hyd_grp.md); selected in [cn2_init.f90](https://github.com/swat-model/swatplus/blob/6f515368525e7d84089ae0f9d33f4c9115de5679/src/cn2_init.f90#L17-L32) |
| $$S_{max}$$ | `smx(j)` | Calculated from $$CN_1$$ in `curno.f90` |
| $$SW$$ | `soil(j)%sw` | Calculated soil-profile water state |
| $$w_1,w_2$$ | `wrt(1,j)`, `wrt(2,j)` | Calculated shape coefficients |
| Wet-condition point | `hru(j)%hyd%cn3_swf` | [cn3\_swf](../../../../../introduction-1/hydrology/hydrology.hyd/cn3_swf.md) in `hydrology.hyd`; set to 0.95 for tile-drained HRUs |
| Frozen-soil coefficient | `bsn_prm%cn_froz` | [cn\_froz](../../../../../introduction-1/basin-1/parameters.bsn/cn_froz.md) in `parameters.bsn`; used only when the second soil layer is frozen |
| Daily retention and curve number | `r2`, then `cnday(j)` | Calculated results |

## Earlier SWAT method

The [SWAT 2009 Theoretical Documentation](https://swat.tamu.edu/media/99192/swat2009-theory.pdf) also described updating retention from its previous-day value, potential evapotranspiration, rainfall, and runoff. That method was added because the soil-moisture method predicted too much runoff in shallow soils; tying the daily curve number to plant evapotranspiration made it less dependent on soil storage and more dependent on antecedent climate:

$$S=S_{prev}+E_o\exp\!\left(-\frac{cncoef\,S_{prev}}{S_{max}}\right)-R_{day}+Q_{surf}$$                                                                          2:1.1.9

This historical method is **not implemented in this version of SWAT+**. The daily routine does not use $$S_{prev}$$, $$E_o$$, or `cncoef` to update retention. The `cn` code in `codes.bsn` is still read, but the code [marks it as not used](https://github.com/swat-model/swatplus/blob/6f515368525e7d84089ae0f9d33f4c9115de5679/src/basin_module.f90#L42).

The earlier method initialized retention at $$S=0.9S_{max}$$.

## Related literature

The soil-water expression in equation 2:1.1.6 also appears in [Tessema et al. (2014), equation 3](https://doi.org/10.1007/s11269-014-0674-3) and [Xu et al. (2012)](https://doi.org/10.5194/hess-16-59-2012), p. 63, equation 6. Xu et al. also give the earlier evapotranspiration-based update as their equation 8, which corresponds to 2:1.1.9, and the daily curve number as their equation 9 (p. 64), which corresponds to 2:1.1.11. These publications describe the base relationships; the bounds, fallback, frozen-soil adjustment, and minimum above describe this SWAT+ implementation.
